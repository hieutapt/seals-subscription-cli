seal-cli CLI

A command-line interface for the Seal Subscriptions Merchant API.

Install

Homebrew (macOS/Linux):

brew install hieutapt/tap/seal-cli

One-line installer (macOS/Linux):

curl -fsSL https://hieutapt.github.io/seals-subscription-cli/install | bash

Install a specific version:

curl -fsSL https://hieutapt.github.io/seals-subscription-cli/install | bash -s -- --version 0.2.0

Quick start

# Save your API token to a profile
seal-cli profile set default --token <your-token>

# List subscriptions
seal-cli subscription list

# Get a specific subscription
seal-cli subscription get <id>

# Cancel a subscription
seal-cli subscription cancel <id>
